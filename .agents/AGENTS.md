# Workspace Rules for HealimBP (해아림한의원 인천부평점)

## 📌 주요 행동 지침 및 상시 적용 규칙

### 0. 🚫 글 작성 매너리즘 및 중복 방지 상시 원칙 (Anti-Repetition & Multi-Dimensional Diversity)
모든 칼럼, 블로그, 티스토리, Q&A 원고 작성 시 시간이 지나도 글이 정형화되거나 비슷해지지 않도록 다음 **5대 다변화 축**을 상시 강제 적용합니다:
1. **🚫 약선차/한방차 내용 일체 기재 금지**: 산조인차, 대추차, 결명자차 등 차(Tea) 관련 내용은 전면 배제하고, 물리적/행동학적 생활 관리 루틴(이완 호흡, 족욕, 수면 환경, 햇볕 쬐기, 근막 스트레칭)으로 구성. (⚠️ 주의: 본문 제목이나 소제목, 썸네일에 '약선차 제외'라는 메타 문구를 직접 노출하지 말고, 자연스럽게 물리적/행동학적 루틴만 작성할 것)
2. **🚫 '한의학 박사' 호칭 일체 사용 금지**: 원장 호칭 및 프로필 표기는 반드시 **'한방침구과 전문의 권형근 대표원장'** 또는 **'한방침구과 전문의 권형근 원장'**으로만 표기.
3. **진부한 상투적 도입부 전면 금지**: "최근 현대인들에게 흔히 발생하는...", "바쁜 현대 사회에서..." 등 클리셰 일체 금지 -> 출근길 만원 지하철, 수험생 시험 직전 복통, 야간 교대근무 얕은 잠 등 구체적 생애주기·직군별 **생생한 임상 상황**으로 시작.
3. **비유(Metaphor)의 다채로운 변주**: 편도체/자율신경 기전 설명 시 브레이크 마모, 스마트폰 백그라운드 앱 100개 과각성, 자동차 엔진 냉각수 고갈(상열하한), 방음벽 없는 방 등 글마다 차별화된 일상 비유 사용.
4. **심층 한방 방제학 & 경혈학 차별화**: 단순 4단계 나열 탈피 -> 증상/체질별 구체적 한약 처방(사역산, 귀비탕, 천왕보심단, 반하후박탕, 온담탕, 억간산, 영계출감탕 등) 및 핵심 혈자리(백회, 신문, 단중, 태충, 풍지 등)의 작용 원리를 글마다 깊이 있게 다변화.
5. **5대 본문 전개 포맷 로테이션 (공장형 템플릿 복붙 절대 금지)**: ① 기전 심층 탐구형, ② 오해와 진실 팩트체크형(O/X 박스), ③ 감별 진단/비교 분석형(비교 테이블), ④ 단계별 회복 로드맵형(타임라인), ⑤ 임상 사례 중심 심층 고찰형(진료 노트)을 균등하게 순환하여 글마다 구조와 레이아웃을 완전히 차별화.
6. **생활 속 힐링 팁의 초구체화**: "충분한 휴식" 배제 -> 4-7-8 이완 호흡, 90분 수면주기, 기상 직후 15분 햇볕 쬐기, 취침 90분 전 족욕, 블루라이트 차단 등 손에 잡히는 구체적 루틴 제시. (원고 본문이나 소제목에 '약선차 제외' 문구를 직접 표기하지 않고 자연스럽게 행동/물리 요법만 작성)

### 1. 블로그 작성 요청 시 (One-Stop All-in-One Dual-Track Protocol)
사용자가 **"[질환/지역] 블로그 써줘/만들어줘"** 또는 **"A패턴/B패턴으로 써줘"**라고 요청하면, 묻거나 확인하지 않고 즉시 원스톱(5종 카드뉴스 + 완성형 원고)으로 일괄 실행합니다:
1. **고화질 5종 카드뉴스/썸네일 이미지 자동 생성 (1080x1080)**:
   - **A패턴 세트**: `01_naver_main_thumbnail.jpg`, `02_point1_cause.jpg` (원인기전), `03_point2_checklist.jpg` (자가진단 체크리스트), `04_point3_treatment.jpg` (맞춤치료), `05_point4_selfcare.jpg` (생활팁 - 약선차 제외)
   - **B패턴 세트 (임상 에피소드 & 심층 로드맵형)**: `01_naver_main_thumbnail.jpg` (썸네일), `02_point1_cause.jpg` (CHAPTER 01 3대 오해와 함정), `03_point2_checklist.jpg` (CHAPTER 02 왜 안 나았을까? 3대 심층 원인 3박스 해설 - ⚠️ 단순 체크리스트가 아닌 심층 기전 해설 카드로 제작), `04_point3_treatment.jpg` (CHAPTER 03 3단계 회복 로드맵), `05_point4_selfcare.jpg` (CHAPTER 04 환자·가족 3대 수칙 - 약선차 제외)
   - **C패턴 전용 세트 (오답노트형)**: `01_naver_main_thumbnail.jpg` (썸네일), `02_point1_wrong1.jpg` (오답 1), `03_point2_wrong2.jpg` (오답 2), `04_point3_wrong3.jpg` (오답 3), `05_point4_treatment.jpg` (맞춤치료)
   - 저장 경로: `static/blog-images/` 및 `static/blog-images/[주제명]/`
2. **3대 포맷 패턴 (A패턴 vs B패턴 vs C패턴) 완벽 지원**:
   - 🅰️ **[A패턴: 정석 가이드형]**: 3대 제목옵션 -> 환자 독백 인트로 -> POINT 01(원인기전 비유) -> POINT 02(자가진단 체크리스트) -> POINT 03(1:1 한방맞춤치료) -> POINT 04(생활속 실천팁 3가지) -> FAQ 3~4선 -> 원장 치유메시지 & 부평점 진료안내 -> 해시태그
   - 🅱️ **[B패턴: 임상 에피소드 & 심층 회복 로드맵형]**: 3대 제목옵션 -> 진료실 리얼 에피소드 프롤로그 -> CHAPTER 01(흔히 겪는 3대 오해와 함정) -> CHAPTER 02(왜 안 나았을까? 3대 심층 원인) -> CHAPTER 03(3단계 회복 로드맵 & 1:1 맞춤 한방치료) -> CHAPTER 04(환자·가족 3대 행동 수칙) -> 원장 직답 Q&A 3선 -> 원장 진료철학 & 부평점 진료안내 -> 해시태그
   - 🅲 **[C패턴: 역발상 팩트 폭격 & 오답 노트형]**: 3대 제목옵션 -> 오답선언 프롤로그 -> CHAPTER 01(오답 1: 대증차단의 역설/의지력 착각) -> CHAPTER 02(오답 2: 발병부위의 오해/작업기억 마비) -> CHAPTER 03(오답 3: 정신력의 함정/각성제 남용) -> CHAPTER 04(오답을 종결짓는 1:1 역발상 맞춤치료) -> 팩트일침 & 원장치유메시지 -> 부평점 진료안내 -> 해시태그
   - (별도 지정이 없으면 주제 특성에 맞추거나 기본 A패턴으로 실행, 사용자가 A/B/C 패턴을 부르면 해당 패턴으로 완벽 작성)
3. **서식 및 출력 철칙**:
   - 📋 **원클릭 복사용 단일 텍스트 블록(Code Block) 제공**: 제목부터 해시태그까지 원고 전체를 하나의 ` ```text ` 안에 온전하게 출력.
   - ⚠️ **[중요 서식 규칙] 마크다운 볼드 표시(`**`) 절대 사용 금지**: `**` 기호 없이 따옴표, 대괄호, 글머리 기호(•, ✓, 💡)로 작성.
   - 🚫 **약선차/한방차 내용 일체 배제**: 행동·물리 요법만 작성.
4. **클릭 가능한 이미지 파일 링크(`file:///...`) 및 폴더 링크 제공**

### 2. 다채널(블로그 5개 / 티스토리 / 홈페이지 / 지식iN / 플레이스) 전략적 운영 원칙
1. **네이버 블로그 5개 (유사문서 방지 & 증상별 분점)**:
   - 계정 간 키워드 자가잠식 방지를 위해 주제/질환군 분리 (정신건강 / 수면·자율신경 / 소아청소년 틱·ADHD / 신체·담적 / 원장 브랜딩)
   - 네이버 스마트블록(의도형/상황형 롱테일 키워드) 맞춤형 타깃팅
2. **티스토리 (구글 SEO & 롱폼 의학 칼럼)**:
   - E-E-A-T 기반 심층 기전 분석, H2/H3 계층 구조, 인천부평점 단독 홈페이지 백링크 자연스러운 유도
   - **질환 특화 FAQ 섹션 필수 포함**: 획일적 질문 복붙 금지, 환자 실전 고민 기반 5대 테마 순환 적용으로 질문 중복 방지 및 E-E-A-T 신뢰도 강화
   - 🖼️ **대표 썸네일 HTML 파일 내장 원칙**: 텔레그램 발송 시 썸네일을 별도 사진(`sendPhoto`)으로 분리 발송하여 채팅창을 어지럽히지 않고, 첨부되는 티스토리 HTML 파일 상단에 완결된 `<img>` 태그로 내장하여 한 번에 전달.
3. **단독 홈페이지 (전환 허브 Hub & 포털 웹문서 1페이지)**:
   - SEO 메타태그 및 Schema.org (MedicalClinic, FAQPage) 유지
   - 방문 환자가 '자가진단 → 전화/카카오톡/네이버예약'으로 전환되는 3대 CTA 상시 연계
4. **네이버 지식iN (고관여 환자 1:1 맞춤 상담)**:
   - 생생한 환자 고민 공감 + 권형근 원장의 4단 전문 의학 답변 + 네임카드 브랜딩
5. **네이버 플레이스 연계**:
   - 모든 채널 콘텐츠 하단에 부평역 7번 출구 위치, 야간진료(월·수·금 20시), 네이버 예약/전화 바로가기 정보 완비

### 3. 홈페이지 및 티스토리 칼럼 작성 시
- **5대 본문 전개 포맷 로테이션 적용**: 단일 템플릿 복붙을 엄격히 금지하고 기전형, 팩트체크형, 감별비교형, 회복로드맵형, 임상에세이형 중 적합한 포맷을 선택하여 전용 UI 컴포넌트(비교표, 타임라인, O/X 카드, 진료노트 등)와 함께 다채롭게 작성.
- 3대 제목 작성 패턴(맨 앞 지역명 / 중간 지역명 삽입 / 순수 질환형) 1:1:1 균등 순환
- **FAQ 다변화 필수 (홈페이지 & 티스토리 공통)**: 획일적인 3대 질문(양약 병행, 치료 기간, 첫 검사) 기계적 반복 절대 금지 -> 질환별 특화 질문 2개 이상 + 5대 테마(증상 대처, 원인 검사, 약물 감량, 호전 순서, 일상·가족 대처) 순환 적용
- **티스토리/블로그 배포 4대 품질 원칙 준수**:
  1. 단락/줄맞춤 완벽 정렬 및 불필요한 `<br>` 남발 방지
  2. 번호형 헤더(`■ 01.`), 소제목(`▶`), 들여쓰기 체크(`  ✓`), 불릿(`  •`), 체질/FAQ 라벨 통일
  3. 마크다운 볼드 기호(`**`) 0% 배제 원칙
  4. 텔레그램 전용 칼럼 봇(`@healim_column_bot`) 4단계 패키지(🖼️ 1080×1080 썸네일 사진, 📋 복사용 대본, 📝 완결형 HTML 파일, 📄 전체 원고 TXT 파일) 일괄 발송
- 상세 규칙: [.agents/rules/column_generation_rules.md](file:///c:/Users/PC/Downloads/home/.agents/rules/column_generation_rules.md)
